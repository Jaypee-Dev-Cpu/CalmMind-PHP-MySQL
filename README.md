# CalmMind — Full-Stack PHP + MySQL Study Companion

## Quick Setup (XAMPP on Windows)

1. Extract this folder into `C:\xampp\htdocs\CalmMind-PHP-MySQL\`.
2. Open **XAMPP Control Panel** and start **Apache** and **MySQL**.
3. Open `http://localhost/phpmyadmin`, click **Import**, select `database.sql`, and click **Go** (creates `calmmind_db`, `users`, and `user_study_data`).
4. Open `http://localhost/CalmMind-PHP-MySQL/` in your browser.
5. Switch to **Register**, create a system account (Display Name, Username, Password), and start tracking exams, tasks, and Pomodoro focus sessions!
